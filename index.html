적나라 개인정보처리방침

최종 수정일: 2026년 10월 18일
이 문서는 적나라 앱이 실제로 데이터를 어떻게 다루는지 있는 그대로 설명합니다. 정식 서비스 출시 전에는 법률 전문가의 검토를 받는 것을 권장하며, 이 문서 자체가 법률 자문을 대체하지는 않습니다.

이 문서가 다루는 것

적나라(Jeoknara)는 실수를 기록하고 AI의 공감 응답과 재발방지 제안을 받는 개인용 기록 앱입니다. 이 문서는 앱을 사용하면서 만들어지는 정보가 어디에 저장되고, 어디로 전송되며, 어떻게 지울 수 있는지를 설명합니다.

기기에만 저장되는 정보

다음 정보는 모두 사용자의 기기 안에만 저장됩니다. 별도 서버로 전송되거나 저장되지 않습니다.

  • 적은 기록의 원문, 발생 시점, 작성 시점
  • 감정 상태(기록 직후 / 다음날 재측정)
  • AI가 분류한 실수 유형과 그 근거(상황·원인·결과 요약)
  • AI의 공감 응답, 재발방지 액션 제안과 그 결과
  • 앱 사용 통계(기록 빈도, 되돌아보기 완료율 등) — 기능 개선 목적이며 기기 밖으로 나가지 않습니다

앱을 삭제하면 이 정보도 함께 삭제됩니다. 설정 화면에서 언제든 개별 기록 또는 전체 기록을 완전히(하드) 삭제할 수 있고, 삭제 전 JSON/텍스트/마크다운 형식으로 내보내기할 수 있습니다.

외부로 전송되는 정보

OpenAI (필수 기능)

기록한 원문 텍스트가 공감 응답·유형 분류·재발방지 액션 제안을 생성하기 위해 OpenAI API로 전송됩니다. 음성으로 기록하면 녹음 파일도 글자로 바꾸기 위해 함께 전송됩니다. 전송된 내용은 응답을 만드는 목적으로만 사용되며, 이 앱이 OpenAI 서버에 별도의 계정이나 로그인 정보를 만들지는 않습니다.

이 전송은 앱이 OpenAI에 직접 하지 않고, 적나라가 운영하는 중계 서버(Supabase 서버리스 함수)를 거칩니다. 앱 안에 OpenAI 인증 키를 넣어두면 누구나 꺼내 쓸 수 있기 때문입니다. 이 중계 서버는 기록 원문과 녹음 파일을 저장하거나 로그에 남기지 않고 OpenAI로 전달하기만 하도록 만들었습니다. 다만 남용을 막기 위해 하루 호출 횟수를 세며, 이때 접속 IP는 원문으로 저장하지 않고 되돌릴 수 없게 변환한(해시) 값만 횟수 집계에 사용합니다. 요청이 서버에 도달하는 과정에서 호스팅 업체(Supabase)의 인프라가 접속 IP 등 통신 정보를 일반적인 운영 목적으로 접할 수 있습니다.

Sentry (오류 보고)

앱이 예기치 않게 오류를 일으키면, 문제를 고치기 위해 오류 정보가 오류 수집 서비스 Sentry로 전송됩니다. 전송되는 것은 오류 메시지와 코드상의 오류 발생 위치(스택 트레이스), 그리고 기기 모델·운영체제 버전·앱 버전 같은 일반적인 실행 환경 정보입니다. Sentry 서버는 전송 과정에서 접속 IP 주소를 접할 수 있습니다. 적은 기록의 원문, AI 응답, 감정 점수는 오류 보고에 담기지 않도록 만들었으며, 화면 녹화나 성능 추적도 사용하지 않습니다. 오류가 발생하지 않으면 아무것도 전송되지 않습니다.

회복 속도 비교, 효과 있었던 액션 공유, 광장 (선택 기능)

아래 세 기능은 기본값이 꺼짐이며, 사용자가 설정에서 직접 켜거나 직접 "공유하기"를 눌러야만 작동합니다. 회복 속도 비교는 실수 유형 코드와 감정 변화량 숫자 하나만 익명으로 전송하며, 원본 기록 문장은 전송하지 않습니다. 광장과 액션 공유는 사용자가 직접 다시 작성한 짧은 글만 전송되며, 기록함의 원문이 자동으로 전송되지 않습니다. 이 기능들은 로그인이 없고, 올린 글에는 작성자를 알 수 있는 정보가 붙지 않습니다.

올린 글은 다른 사용자에게 공개됩니다. 앱에서 올린 글을 직접 지울 수는 없으므로, 삭제를 원하면 아래 문의처로 알려주세요. 연락처·이메일·링크는 올릴 수 없으며, 서버가 이를 비롯해 부적절한 표현을 자동으로 걸러냅니다. 다른 사용자는 글을 신고할 수 있고, 서로 다른 접속 환경에서 신고가 여러 건 쌓이면 글이 자동으로 숨겨지며, 이후 운영자가 검토해 복구하거나 삭제합니다.

남용(도배·스팸)을 막기 위해 서버는 글을 올리거나 신고할 때 하루·시간당 횟수를 셉니다. 이를 위해 앱이 처음 실행될 때 만든 무작위 기기 ID와 접속 IP 주소를 되돌릴 수 없게 변환한 값(해시)만 사용하며, 신고 시에는 신고 사유와 대상 글, 그리고 같은 사람이 중복 신고하지 못하게 하는 해시 값이 함께 저장됩니다. 이 값들은 어떤 글을 누가 올렸는지 연결되어 저장되지 않습니다. 내가 신고한 글의 목록은 내 기기에만 저장됩니다.

광고·추적

이 앱은 광고를 표시하지 않으며, 사용 행태를 분석하거나 광고 목적으로 추적하는 도구를 사용하지 않습니다. 위에서 설명한 오류 보고(Sentry)만 오류가 발생했을 때 동작합니다.

계정

회원가입이나 로그인 기능이 없습니다. 모든 데이터는 사용자의 기기에 귀속됩니다.
